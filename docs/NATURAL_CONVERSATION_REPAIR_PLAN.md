## 用户应得到什么

有 TCP、UDP 两份报告时，用户说“TCP，不对，我想改 UDP”，助手不能给出 TCP 草稿。首版对同一句里互相冲突的两个目标**再问一次**；对“我选 UDP，只改报告”则直接续接。没有历史报告时，用户按提示贴出的原文也能完成同一请求。已有材料、明确意图和明确归属分别判断，不能从其中一项推导另外两项。

## 决策规则与实现边界

**A．先确定回复关系，再选择对象。** 对用户已观察到的候选，扫描整条回复中用于选择、否定、更正、追加的分句；材料正文、引文和“保留 TCP 测量值”等编辑要求不作为选择指令。纯函数返回“唯一选择 / 有冲突 / 非选择”，不用一个空值同时表示后两种。命中冲突时用有界的候选名追问，保留等待对象，不进入查证、生成或归档兜底；不得将冲突文本作为最终编辑要求。保留既有明确排除再选择（“不是 TCP，是 UDP”）。无法可靠解析时允许显式选择；候选截断、版本失效或多个等待问题可匹配时不猜。

**B．由用途决定材料怎么用。** 解析器保留原串，用原串的区间提取材料；只在指令副本上做归一化。引号内的术语不代表改写，正文内的“保存/执行”也不代表指令。先处理明确独立的问答、归档、查证或改写，再对只有“原文：……”的输入判断是否是补充。显式归档走原归档入口与门控。带“原文：”的段落保留内部引号、后续事实、数字和换行，仅在可判定的外部指令边界结束。明确要求处理多段引文时按顺序保留所有原文范围；无法区分指令与材料时问具体哪段，不静默取第一段。旧入口共享解析规则时必须一起跑回归，不改其协议。

**C．区分找不到历史对象和没有可用材料。** 去掉操作词后为空就直接返回零候选。零候选和“都不是”都允许用户给新主题重新检索，不能要求先拒绝一个根本不存在的选项。普通输入只匹配已观察、仍有效的问题；新主题匹配不唯一时给显式回复入口。用户明确贴原文时，以本轮消息 ID 作为材料来源，保留原请求与修改要求。已有要求则生成；没有要求只问怎么改。全程不因补材料创建 Entry 或 WorkItem。

这里有一个实际的数据约束：v12 的 resolved 记录必须选中 Entry 或 WorkItem，不能把聊天消息 UUID 填进这两个字段。建议实施 C 时增加**本轮材料消息引用**（可空外键）作为第三种互斥绑定，只接受本交互已关联的用户材料消息。此引用用于恢复和引文展示，不进入长期检索或执行提案。用下一次正式迁移调整 CHECK，保留原消息、选项、审批绑定及旧 resolved 的含义；同步更新新预览投影，旧澄清接口只投影原先能表达的对象。实施前先用临时 v12 库验证迁移/回滚，再接应用层。原请求、回复关系与版本一起短事务提交；模型在事务外调用，发布前重验卡片、范围和来源有效性。

**快照保护的是一次消费。** 显式 replyTo 始终重验指定问题和版本。无显式回复且已确认为完整独立输入时，不因其他页面改变等待集合返回冲突，也不读取新问题来推断其含义。可能是自然回复时仍校验已观察集合、消息上界、重复引用及候选；快照不足或陈旧不得消费或静默改成“回复最新”。保留输入 schema、同键异载荷冲突及现有 20 个等待问题上限。

**D．把历史提问、当前等待、最近一次回答结果区分开。** 历史消息保留原问句；交互投影只在 awaiting 非空时显示当前问题。成功时显示“已根据 TCP 实验生成草稿”及来源入口；缺材料显示新问题；可重试模型失败显示失败和按钮；取消、失效不可重试。由服务端按已持久化的结果类型生成这些状态，不能解析中文提示或以 promptMessageId 是否为空区分新旧卡。旧记录无法证明是失败时，不推断可重试。

重试锚定**失败的助手结果消息**，包括按标题直接命中、从未提问的 Entry。建议在新预览投影提供可空 retry 引用（交互 ID、revision、失败结果消息 ID），以单独严格的重试命令消费，保留旧命令兼容。服务端在同一事务核对“本卡、最近失败、未消费、来源仍有效”，领取本次尝试，完成后写结果；同 requestId 重放只返回原回执，另一个页面重复点击不能再次触发模型。网络响应丢失沿用原请求核对，不把它当作一次新的模型重试。无关联卡片的独立改写失败时也不能承诺有卡片按钮。刷新和重启按后端事实恢复，不把运行中的未知结果标成可放心重发。

## 实施顺序和完成条件

1. 各批次先把对应反例变为失败回归，再修实现并同时跑正例；不要改旧断言来迎合新行为。A 可先合并止住错绑。B 在 C 前落地，C 才能分清独立输入和补充。D 使用 C 的对象和消息关联，不另建任务系统。
2. 涉及迁移与 API 的批次先确定类型、旧库迁移和存储约束，再接应用、HTTP 和网页；严格 schema 派生 DTO，运行 OpenAPI 生成/漂移门禁。优先扩展小型纯函数与现有存储服务，不继续把所有判定加进主对话服务。关闭预览是入口回退，不是降级数据库。
3. 每批提交附失败样例、修复后证据和未测项；A–D、联合门禁及隔离网页操作全部通过才交接 [C4](MAIN_CONVERSATION_PLAN.md)。C4 再做同样本质量/操作成本对照并决定默认入口。此计划不授权真实模型预算，也不引入腾讯记忆、自动归档、文件写入、侧栏改版或新的后台会话。
