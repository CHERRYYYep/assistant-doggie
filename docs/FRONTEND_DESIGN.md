# 前端初版改版

日期：2026-11-12。范围是已有 MVP 的信息结构与视觉改进，不新增业务权限、远程访问或多人会话。

## 设计方向

参考 [Beautiful UI](https://www.beautifului.dev/) 的侧栏导航、细边框卡片、紧凑状态与宽松输入区，结合 Doggie 的归档确认和长期记忆流程重新设计。使用系统字体、现有原生 TypeScript 模块和 CSS，不引入组件库、远程字体或额外运行依赖。浅色使用灰白底与紫色强调，深色沿用系统偏好。

## 工作区划分

- **长期对话**：默认入口。历史记录独立滚动，输入区在布局中占据真实空间，不再固定覆盖消息。欢迎区说明记录与待办示例。
- **记忆空间**：活跃 Bucket 列表与详情并排，窄屏上下排列。保留原文、摘要、Entry 撤销和 Bucket 删除操作。
- **待办计划**：独立 Agenda 卡片区。显示五状态、分别标注计划和截止时间，优先展示来源 Bucket 名称；保留计划编辑、重复推进、重新打开和冲突刷新。
- **查询记忆**：独立自然语言输入、查询理解、汇总答案和证据区域。
- **Agent 与任务**：通过折叠工具导航进入。后台任务可折叠，CLI Agent 和工作目录登记默认收起；提案与显式批准仍是两步操作。

导航只切换已挂载节点的可见性，保留未发送草稿、查询内容和表单。来源操作打开记忆空间；移动、撤销后的后台详情更新不会强制切换当前页面。导航有当前页面标记，键盘按钮可操作，切换后焦点进入工作区。状态提示位于共享顶部，其他页面的错误仍可见。

原“新对话”按钮只清空输入，现改名为“清空输入”，并返回长期对话；不会创建会话或清除历史。

聊天任务结束、归档确认、移动、撤销或删除 Bucket 后同步刷新 Agenda，避免页面继续显示旧待办。

## 预览

使用 Node.js 24 或更新版本，在仓库根目录执行 `npm start`，然后打开默认地址 <http://127.0.0.1:8787/>；以实际配置的 loopback 地址为准。需要已配置模型的本地环境。若尚无 `.env`，才从 `.env.example` 创建并填写；不要覆盖已有配置。

前端资源在服务启动时加载。修改源码后重启服务，再刷新浏览器；没有热更新或独立前端开发服务器。不要直接以文件方式打开 `web/index.html`。

- `npm run check`：414 项后端测试、60 项前端测试及格式、类型、OpenAPI 漂移检查通过。
- 扩展真实模块入口测试：切换工作区的可见性与当前页标记、草稿与查询结果保留、来源打开记忆详情、清空输入。保留现有安全与业务回归。
