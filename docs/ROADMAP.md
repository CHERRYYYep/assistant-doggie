# 产品路线图

> 实现语言迁移：自 2026-08-04 起，仓库按 [`RUST_MIGRATION.md`](./RUST_MIGRATION.md) 渐进迁移到 Rust。产品版本目标保持不变；每项能力在 Rust 通过契约和数据兼容验证后才切换所有权。

## v0.1：数据与输出契约

目标：不用 AI 也能可靠存取数据，并明确 LLM 输出边界。

- SQLite、Bucket、Entry 和派生记录表。
- Bucket 基础读写与详情。
- Pydantic 分类、提取 Schema。
- 数据库和 Schema 单元测试。

## v0.2：分类评估基线

目标：在接入真实分类前，先定义可重复的质量标准。

- 50～100 条人工标注分类案例。
- action、Bucket 选择、询问和严重误合并指标。
- mock 回归与独立真实模型评估命令。
- Prompt、模型和结果版本记录。

## v0.3：风险感知分类

目标：稳定判断追加、新建或询问，并避免污染长期记忆。

- OpenAI Structured Outputs 封装。
- 当前焦点和有限候选 Bucket。
- 候选 ID 服务端校验。
- 置信度门控与经验校准。
- 分类原因和后续纠错记录。

## v0.4：结构化提取与完整归档

目标：分类通过风险门控后，完成结构化保存。

- Summary、Todo、Evidence、Timeline 和 Decision 提取。
- 提取结果入库。
- Bucket 滚动摘要。
- `archive_user_input` 单事务闭环。

## v0.5：纠错优先 MVP

目标：分类错误可以快速修复并形成学习信号。

- 移动最近 Entry。
- 同步移动派生记录。
- 修改 Bucket 类型和新建 Bucket。
- Correction 前后快照。

## v0.6：Streamlit 可使用界面

目标：用户能够输入、确认、查看和纠错。

- 一个输入框。
- 活跃 Bucket 与当前焦点。
- 分类原因和不确定性提示。
- 最近归档结果与 Bucket 详情。

## v0.7：找回与 MVP 验收

目标：能够找回长期上下文，并达到分类优先的质量门槛。

- SQLite 关键词搜索。
- 固定分类、提取、纠错、搜索回归。
- 高置信度自动归档准确率达到 90%。
- 数据备份和基础导出准备。

## v0.8：长期记忆增强

- 用户偏好与重复纠错学习。
- Bucket 生命周期和合并建议。
- 语义搜索与来源引用。
- 更细粒度的提取对象和质量评估。

## v0.9：更多输入与工作流集成

- 文件、截图和附件。
- 日历、GitHub Issue、Slack/飞书等入口。
- 浏览器插件或快捷输入。

## v1.0：个人长期可用版本

- 稳定的分类与纠错闭环。
- 数据备份、Markdown 导出和设置页。
- 可解释、可找回、可持续演进的私人事务记忆。
