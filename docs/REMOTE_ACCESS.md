# 个人远程接入：接口与安全边界预留

日期：2026-11-03。状态：仅文档设计预留，未实现、未启用；这里的操作名不是已注册 API、冻结 DTO 或可调用端点。

## 1. 用户意图与范围

同一个人在电脑运行 Doggie、本机数据库和已批准任务，通过手机浏览器配对接入，继续对话、查询记忆、查看状态及批准/取消指定任务。它不是多用户共享、远程桌面、手机直接执行 CLI 或多份本地数据库的离线合并。

用户希望免去手动内网穿透，并由产品提供明确的安全接入流程。扫码是配对入口，跨网络连接仍需可达通路。中继、直连、自托管、托管服务以及加密协议都未定案；目前不建设这些设施。

## 2. 未来接入边界

```text
手机交互层
    ↓ 经认证且受限的远程传输（未来）
电脑端远程适配器（未来）
    ↓ 已验证的操作和设备身份
本地应用服务 / PendingAction / 任务队列
    ↓
本机 SQLite 与固定执行器
```

- 应用服务拥有业务规则；远程层不得复制一套归档、审批或任务状态机。
- 手机和电脑的设备身份、网络连接会话、聊天记录与 CLI AgentSession 是不同概念，不复用一个 session ID 充当全部身份。
- 数据和执行以电脑为中心；未来页面应显示电脑/工作区、连接状态和操作结果，电脑离线不得冒充任务成功。
- 当前本地 loopback 监听、Host/Origin、JSON、资源限制和 MCP allow-list 保持不变。不得为预留而监听 `0.0.0.0` / `::`、开放宽泛 CORS、转发所有本地端点或添加无认证写入口。

## 3. 逻辑操作预留

以下是未来适配器需要对接的能力，不预定 HTTP 路径、传输协议或代码接口。实施前须明确 schema、权限、错误码和测试，再注册端点。

| 操作组 | 预留能力 | 必须满足的语义 |
|---|---|---|
| 配对 | 电脑发起、手机申请、电脑确认、过期/拒绝 | 短时、一次性、不可重复兑换；二维码不包含长期通行凭证 |
| 设备 | 查看设备、撤销设备、关闭远程访问 | 凭证与连接可撤销；设备身份不能直接等于审批授权 |
| 消息与记忆 | 提交输入、读取历史、查询/读取 Bucket | 复用领域门控、响应合同与资源预算；最小可见范围 |
| 待确认动作 | 读取提案、批准/拒绝指定动作 | 与具体动作、原文/参数及版本绑定；沿用现有防伪造/防重放规则 |
| 任务 | 读取状态、观察事件、取消指定任务 | 任务 ID 绑定、稳定终态；断线不等于取消，重连不重复执行 |
| 恢复与审计 | 请求标识、结果核对、失效凭证错误 | 处理丢失响应/重复命令；先定义每个写操作的幂等或恢复合同 |

已有应用服务可以作为未来适配目标，但当前 HTTP POST、SSE 和审批并未获得远程认证、全局幂等或事件补发保证。预留不能被描述为已支持远程访问。

## 4. 实施前必须解决的事项

- 设备信任建立、电脑端明确确认、凭证保管/轮换/撤销、丢失手机后的恢复，以及连接断开与重新授权。
- 传输机密性与中继信任：是否需要端到端加密、中继可见哪些元数据、设备密钥验证及手机网页代码分发的信任。TLS 不自动代表端到端保密；采用成熟协议和库，不自行设计密码协议。
- 认证设备可读取和操作哪些能力；不得允许任意 shell、任意文件读取、模型自动批准或放宽 CLI 权限。
- 超时、限流、大小/连接上限、重连/去重预算和审计脱敏。短期配对凭证和长期密钥不得写入日志或二维码历史。
- 电脑休眠/离线、网络切换、重复请求、事件缺失、撤销中途连接以及版本不匹配时的真实状态展示。

未来验收至少覆盖配对过期与重放拒绝、未认证访问拒绝、撤销设备生效、动作绑定、重复批准仅执行一次、断线恢复无重复写入、凭证脱敏，以及本地安全门禁不回退。

## 5. 当前不做的工作

不添加路由、表、设备令牌、连接进程、relay 服务、二维码库或占位 TypeScript 接口；不改变监听配置。远程接入方案与是否自托管尚需未来决定。当前优先级见 [产品决策 Q1–Q4](PRODUCT_DECISIONS.md)。
